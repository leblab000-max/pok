# Локальная браузерная песочница Poker AI

Только собственная офлайн-среда с виртуальными фишками. Движок Hold’em и четыре
существующие стратегии используются без изменения правил и алгоритмов решений.
Подключения к внешним покерным площадкам нет. Бесплатные Python / Git / Playwright;
платные API, аренда сервера и публикация сайта не нужны.

## Windows: запуск двойным щелчком

Откройте **`start_poker.bat`** в корне копии ветки `dev/poker-simulator-v03`.
Локальный адрес после запуска: **http://127.0.0.1:8765/**. Терминал оставьте открытым.
Первый запуск требует интернета для бесплатных установок; повторный использует
уже созданное окружение и браузер. При отсутствии Python 3.12 или Git запускатель
пытается установить их через winget; штатный Windows/UAC может запросить разрешение.
При отсутствии winget он выводит точную причину и прекращает запуск.

Запускатель:

1. Проверяет Python **3.12** и Git.
2. Получает обновления только рабочей ветки и применяет только fast-forward.
3. Если есть локальные изменения, локальные коммиты, которые нельзя fast-forward,
   или открыта другая ветка, сохраняет исходную папку и индекс без изменений и
   создаёт отдельную копию в `%LOCALAPPDATA%\PokerAILab\checkouts\<id>`.
   Путь реально запущенной копии выводится в терминале. Никаких stash/reset/force.
4. Создаёт `.venv-sandbox`, устанавливает закреплённые версии из
   `requirements-sandbox.txt` и Chromium в `.sandbox-browsers`.
5. Запускает HTTP-сервер **только на 127.0.0.1** и отдельный Chromium с профилем
   `runs\sandbox\browser-profile`. Основной профиль Chrome не используется.

`main` не переключается и не изменяется. Если сеть недоступна, чистая рабочая
копия запускается с предупреждением без синхронизации. Для грязной копии безопасное
клонирование требует сети: при ошибке исходные файлы остаются на месте.

На машине без Python/Git и без winget потребуется установить бесплатные Python 3.12
и Git стандартным установщиком. Нельзя заявлять об успешной установке на конкретный
ПК до реального запуска на нём.

## Управление

- **Запустить / Продолжить** — автоматическая игра AI за все места.
- **Пауза** — после подтверждения ни одно новое действие не применяется. Текущий
  расчёт может завершиться; его рекомендация видна, но не исполняется.
- **Шаг AI** — ровно одно игровое действие, после чего сессия остаётся на паузе.
- **Экстренная остановка** — защёлкнутая остановка сессии. Незавершённый расчёт
  может закончиться, но его результат будет отброшен. Для новой игры нужен сброс.
- **Новая сессия** — останавливает прежнюю игру и создаёт новую; журнал сохраняется.
- На паузе, когда ход места 1, доступны только законные **Fold, Check, Call, Bet,
  Raise, All-in**. Сумма Bet/Raise — **всего внесено на текущей улице**, а не добавка.
  All-in при нехватке фишек на колл становится коротким коллом; закрытое право на
  рейз не обходится. Устаревшее действие с другим ID хода отклоняется.

Закрытие окна тестового Chromium останавливает принадлежащий ему сервер и AI.
Второй запуск в той же папке отклоняется файловой блокировкой; чужие процессы не
завершаются. После аварии блокировка ОС освобождается, незавершённая сессия в SQLite
помечается `interrupted`. Автоматического продолжения частично сыгранной раздачи нет.

## Панель и честная интерпретация чисел

Панель показывает карты места 1, открытый борд, банк, стеки, кнопку и блайнды,
выбранное действие, время расчёта стратегии, контекст решения и результаты сессии.
Скрытые карты соперников не передаются в API, журнал или расчёт стратегии.

По умолчанию используется **Portfolio v0.6 fixed**: существующий портфель с
`adapt=False`, `rollouts=8`, числом samples из панели и сохранённой калибровкой
`reports/v05/calibration.json`, если файл доступен. Mathematical, Advanced и Adaptive
сохранены как переключаемые варианты. Противники используют существующие TAG/LAG/
Passive. Это испытание интерфейса, а не новая оптимизация или оценка прибыльности.

- Equity в панели — **отдельный** воспроизводимый Monte Carlo расчёт доли банка
  против равномерных неизвестных рук. Win — победа без дележа; tie — участие в дележе.
  Это не внутренние диапазоны стратегии и не вероятность денежной прибыли.
- Оценка относится к состоянию **перед указанным действием**, а не к более позднему
  борду. Малая выборка samples даёт шумный результат. Карты ещё не сделавшего ход
  соперника и будущий борд никогда не используются.
- Время решения измеряет вызов стратегии, без ожидания пользователя и без отдельной
  диагностической equity. Время установки и отрисовки также не включено.
- Обоснование содержит фактически доступный маршрут алгоритма, pot odds и эффективный
  стек. Это контекст алгоритма, а не выдуманная цепочка рассуждений или точный EV.
- Изменение фишек суммируется только по **завершённым** раздачам; текущий банк отдельно.
  Число действий AI в панели относится к месту 1. Итоговое место — после турнира.
- Исторические отчёты v0.6 относятся к их замороженным коммитам. Новые необязательные
  хуки движка меняют общий source hash; артефакты selection не переписываются и
  проверки хеша в исследовательском CLI не отключаются. Для точного воспроизведения
  старого исследования используйте указанные в нём исходные коммиты.

## Данные и изоляция

`runs/sandbox/sandbox.sqlite` содержит сессии, конфигурацию, реальные применённые
действия, наблюдение героя до решения, рекомендацию AI и финальный результат.
`decisions.jsonl` — добавляемый журнал. `errors.log` — ротируемый журнал ошибок
(1 МБ × 4 файла). В интерфейсе показаны последние 200 событий, на диске сохраняются
все. SQLite и JSONL растут: при длительных испытаниях контролируйте свободное место
и архивируйте файлы **после закрытия** программы. Автоматического удаления данных нет.

HTTP API требует случайный токен сессии, проверяет Host/Origin, не разрешает CORS,
не раздаёт файлы вне списка статических ресурсов. Токен не записывается в URL и
журналы. Запущенный Chromium блокирует запросы страниц к внешним адресам; никаких
скрытых режимов, антибот-обходов и маскировки автоматизации нет. Это локальный
однопользовательский инструмент, не публичный сервер с системой аккаунтов.

## Linux / разработка / воспроизведение проверок

```bash
python3.12 scripts/bootstrap_sandbox.py --no-sync --setup-only
export PLAYWRIGHT_BROWSERS_PATH="$PWD/.sandbox-browsers"
.venv-sandbox/bin/python scripts/run_sandbox.py                  # с рабочим столом
.venv-sandbox/bin/python scripts/run_sandbox.py --serve-only     # сервер без GUI
```

На Linux при сообщении Playwright об отсутствующих системных библиотеках:
`.venv-sandbox/bin/python -m playwright install-deps chromium` (может требовать sudo).
Сервер не выставляется в интернет; для VPS используйте свой SSH-туннель к 8765.
Стандартный движок по-прежнему не требует сторонних Python-пакетов.

```bash
python3.12 -m unittest discover -s tests -v
POKER_BROWSER_TESTS=1 PLAYWRIGHT_BROWSERS_PATH="$PWD/.sandbox-browsers" \
  .venv-sandbox/bin/python -m unittest discover -s tests -v
PYTHONPATH=. python3.12 scripts/stress.py
```

PowerShell после первичной установки:

```powershell
$env:POKER_BROWSER_TESTS = '1'
$env:PLAYWRIGHT_BROWSERS_PATH = "$PWD\.sandbox-browsers"
.\.venv-sandbox\Scripts\python.exe -m unittest discover -s tests -v
```

Workflow `.github/workflows/sandbox.yml` запускает тесты с настоящим Chromium на
Ubuntu и Windows; Windows дополнительно вызывает bat в режиме установки без
повторной синхронизации. Скриншоты сохраняются в артефактах Actions на 7 дней.
`--no-sync` предназначен для разработчика/CI с уже выбранной ревизией.
Для прекращения HTTP-only режима нажмите Ctrl+C в терминале.
